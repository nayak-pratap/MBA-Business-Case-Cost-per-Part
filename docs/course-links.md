# Where management concepts show up

This calculator was designed to carry shop-floor engineering questions through to a business decision. These are the management ideas it applies, in plain words. The concepts are standard; the examples are the calculator's own.

| Idea | Where it shows up in the calculator |
|---|---|
| Fixed and variable costs | Machine time is a cost that runs with every part. The one-time cost is the fixed amount to recover. |
| Cost drivers (activity-based costing) | Cost per part is split into machine time, insert and tool change, so you can see which driver produces the saving. Tool changes are an activity that cost money in proportion to how often they happen. |
| Break-even and margin of safety (cost-volume-profit) | Break-even parts is the one-time cost divided by the saving per part, the same shape as fixed cost divided by contribution margin. Margin of safety is the volume left after break-even. |
| Sunk and relevant costs | Only future costs that differ between the tools count. Tooling you already own is ignored. |
| Opportunity cost | Time on a machine that is not the bottleneck has no alternative use, so it is not counted as money. |
| Bottlenecks and capacity (process analysis) | The bottleneck switch: a shorter cycle only adds output if the machine limits output. |
| Confidence intervals with unknown sigma | The t-based interval around the trial's average tool life. |
| Sample size for estimating a mean | The "Plan a trial" panel and the edges-to-test estimate. |
| Decision-making under uncertainty | The pessimistic, expected and optimistic cases, and the Go, Conditional and No-go verdict. |
| Sensitivity analysis | The table that moves each input by 10% and shows what happens to payback. |
| Descriptive, predictive and prescriptive analytics | The calculator is prescriptive: it recommends an action from the data rather than only describing it. |
